# RPPS Static HTML/JavaScript – Version 3

Open `index.html` directly in a browser. No Node.js, npm, Python or backend is required.

## Added in this version
- Separate admin CSV page for user skills, projects, recommendation analytics, analytics points and task status.
- Skill CSV upload updates existing user skills by email.
- Recommendation analytics CSV includes match percentage, matched skills, missing skills and analytics points.
- Project detail workspace contains Daily, Weekly, Monthly and Yearly tabs.
- Clicking a tab lists its tasks in the left sidebar.
- Clicking a task populates the project details form.
- Project video section supports YouTube URLs and direct video URLs.
- Apply button removed.
- Saving a workspace marks the selected task active and updates category counts with priority information.
